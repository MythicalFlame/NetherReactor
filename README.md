# NetherReactor

NetherReactor is a Minecraft plugin for [PaperMC](https://papermc.io/) that allows you to add custom content like custom items and effects into the game, as well as modify game code using JVM instrumentation.

This is a better and rewritten version of the [original NetherReactor library](https://github.com/MythicalFlame/NetherReactorLegacy), which originally added "fake" custom content. This new version injects real custom content into the game's registries. Additionally, this new version also has the ability to modify the game's code by transforming or redefining classes.

## Usage

Please see [the wiki](https://github.com/MythicalFlame/NetherReactor/wiki) for information on how to use this as a server admin or developer.
